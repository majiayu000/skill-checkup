skill-checkup

Audit and lint the Agent Skills (SKILL.md) installed for Claude Code and Codex. Read-only, offline, no dependencies.

uvx --from git+https://github.com/majiayu000/skill-checkup@v0.2.1 skill-checkup

No uvx? pipx run --spec git+https://github.com/majiayu000/skill-checkup@v0.2.1 skill-checkup. Python 3.10+. Source on GitHub.

What it finds

Broken skillsLinks to nowhere, missing referenced files or commands, and same-name copies in ~/.claude/skills and ~/.agents/skills that drifted apart.
Competing descriptionsSkills so alike that they fight over the same requests.
Description gapsRequests you keep typing that a skill's body handles but its description never mentions, so it never triggers.
One-sided skillsLoaded by both Claude Code and Codex, used by only one, with which copy is safe to delete.

Built into Claude Code, /skill-doctor lists unused Claude Code skills and their token cost. skill-checkup covers what it doesn't, across both agents.

FAQ

Why isn't my Claude Code skill triggering?

The agent decides from the skill's description. If the description doesn't mention what you ask for, the skill won't fire even when its body can do the job. skill-checkup finds repeated requests that match a skill's body but not its description, and skill-checkup replay <skill> --description "..." checks a rewording against your real requests.

How do I keep skills in sync between Claude Code and Codex?

Claude Code reads ~/.claude/skills; Codex reads ~/.agents/skills. Copies drift. skill-checkup reports same-name copies whose contents differ, links that point nowhere, and skills one agent loads but never uses, with whether deleting that copy is safe.

Is this the same as /skill-doctor?

No. Use /skill-doctor for unused Claude Code skills and their token cost. Use skill-checkup for broken and drifted skills, competing or incomplete descriptions, Codex, and skills used by only one agent.

Does it send my conversations anywhere?

No. It reads local session logs to count skill use, changes nothing and sends nothing. Your messages stay out of the report unless you pass --show-examples.

Accuracy

Findings were hand-checked against the author's machine (106 skills, 90 days of logs), 15 at a time: 3/15, then 7/15, then 14/15 after fixes. Details and limits are in the README. False-positive reports are welcome as issues.
